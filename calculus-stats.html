Calculus and statistics formulas

A short set of first tools: differentiating a power, evaluating a basic limit, summarizing a data list, and computing a simple probability.

Power rule

For a real number $n$, the derivative of $x^n$ is

$$\frac{d}{dx}\, x^n = n x^{n-1}.$$

Differentiation is linear, so constants factor out and sums are differentiated term by term: $\dfrac{d}{dx}\bigl(af(x)+bg(x)\bigr) = af'(x)+bg'(x)$. The derivative of a constant is $0$. To check a longer polynomial, a math solver can return the same term-by-term result.

Worked example

Differentiate $f(x) = 3x^4 - 2x + 5$.

  1. $\dfrac{d}{dx}(3x^4) = 3\cdot 4x^3 = 12x^3$.
  2. $\dfrac{d}{dx}(-2x) = -2$ and $\dfrac{d}{dx}(5) = 0$.
  3. So $f'(x) = 12x^3 - 2$.

Basic limits

If a function is a ratio of polynomials and the numerator and denominator both approach $0$, factor or otherwise cancel the shared term before substituting. Direct substitution works when the simplified function is continuous at the point. A math solver is useful for confirming the cancelled form and the final value.

Worked example

Evaluate $\displaystyle\lim_{x \to 2}\dfrac{x^2-4}{x-2}$.

  1. Direct substitution gives $0/0$, which is indeterminate, not a value.
  2. Factor the numerator: $x^2-4 = (x-2)(x+2)$.
  3. For $x \neq 2$, the fraction simplifies to $x+2$.
  4. Therefore the limit is $2+2 = 4$. The original function has a hole at $x=2$, but the limit still exists.

Mean, median, and mode

For a finite list of numbers:

  • The mean is the sum of the values divided by how many values there are.
  • The median is the middle value after the list is ordered. If there are two middle values, average them.
  • The mode is the value that appears most often. A list can have more than one mode, or no unique mode.
Worked example

For the data set $4,\ 7,\ 7,\ 9,\ 13$:

  1. Mean: $(4+7+7+9+13)/5 = 40/5 = 8$.
  2. Median: the ordered list already has five entries, so the middle one is $7$.
  3. Mode: $7$ appears twice, and every other value appears once, so the mode is $7$.

Simple probability

If every outcome in a finite sample space is equally likely, the probability of an event $A$ is

$$P(A) = \frac{\text{number of favorable outcomes}}{\text{number of possible outcomes}}.$$

If $A$ and $B$ are independent, $P(A\text{ and }B) = P(A)\,P(B)$. If they cannot happen together, $P(A\text{ or }B) = P(A)+P(B)$. For a two-event product like the example below, a math solver can confirm the multiplied fractions.

Worked example

A fair coin and a fair six-sided die are rolled together. What is the probability of getting heads and a $6$?

  1. The coin and die do not affect each other, so the events are independent.
  2. $P(\text{heads}) = 1/2$ and $P(6) = 1/6$.
  3. $P(\text{heads and }6) = \dfrac{1}{2}\cdot\dfrac{1}{6} = \dfrac{1}{12}$.
